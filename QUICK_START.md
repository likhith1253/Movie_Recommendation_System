# 🚀 Quick Start Guide

## Getting Started in 3 Steps

### 1️⃣ Install Dependencies
```bash
pip install -r requirements.txt
```

### 2️⃣ Run the Application
```bash
python main.py
```

### 3️⃣ Try These Sample Inputs

## 🎯 Best Sample Inputs

### **Get Movie Recommendations**
Try these movie titles:
- `Inception` - Get similar mind-bending thrillers
- `The Dark Knight` - Find other superhero/crime films
- `Toy Story` - Discover family-friendly animations
- `The Matrix` - Explore sci-fi action movies
- `Pulp Fiction` - Find Tarantino-style films

### **Advanced Search**
Try this query with filters:
- **Query**: `"A movie about space exploration"`
- **Filters**: Year after 2000, Rating 7.0+, Max runtime 180 min
- **Results**: Interstellar, Gravity, The Martian

### **Find Movies by Genre**
Try these genres:
- `Sci-Fi` - Science fiction films
- `Animation` - Animated movies
- `Thriller` - Suspenseful films
- `Action` - Action-packed movies

### **Explore by Director**
Try these movies to find their directors' filmography:
- `Inception` → Christopher Nolan films
- `Pulp Fiction` → Quentin Tarantino films
- `Avatar` → James Cameron films
- `Jurassic Park` → Steven Spielberg films

## 📊 What You'll See

The system will show you:
- **Movie Tables**: Beautifully formatted tables with title, year, rating, runtime, and genres
- **Similarity Scores**: How similar recommended movies are (percentage)
- **Director Filmographies**: All movies by the same director
- **Filtered Results**: Movies matching your specific criteria

## 🎬 Example Session

```
1. Select: 🎯 Get Movie Recommendations
2. Enter: Inception
3. How many: 6
4. See: The Matrix, Interstellar, Shutter Island, etc.

5. Select: 🎬 Explore by Director
6. Enter: Inception
7. See: All Christopher Nolan films (The Dark Knight, Interstellar, etc.)
```
